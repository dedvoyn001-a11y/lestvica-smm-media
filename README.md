# lestvica-smm-media

Слайды каруселей «Лествицы» для автопостинга в Instagram: Instagram забирает
картинки только по публичной ссылке, а до сервера проекта в Москве сборщик Meta не
доходит. Здесь только картинки, которые и так публикуются в соцсетях, — без кода,
данных и ключей. Путь: `carousels/<ID>/NN.jpg`.
